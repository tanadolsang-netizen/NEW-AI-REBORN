# ASTRAL

Astrology tools built around your daily life, not just abstract predictions. Offline-first calculations with optional journaling, planetary energy, and timing guidance.

## Getting started
- Frontend: `npm run dev`
- Backend: from `astral-backend`, run `uvicorn src.main:app --reload`

## Notes
This project intentionally uses clean, everyday language in the interface — no system, API, model, token, or interface terminology exposed to users.
